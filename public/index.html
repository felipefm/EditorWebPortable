Editor Portable

Este navegador não grava direto nos seus arquivos. Por isso o botão Baixar salva uma cópia na pasta de downloads. Seu texto continua salvo automaticamente neste navegador. Para gravar no arquivo original, use Chrome ou Edge no computador.

Sessão e backup
Neste navegador Salvo automaticamente
Arquivo de backup Nenhum arquivo configurado. A sessão fica salva só neste navegador.

Nada é enviado para servidores. Os dados ficam neste navegador e no arquivo que você escolher.

Pastas

Este navegador não abre pastas do computador.

Use o Edge ou o Chrome no computador. No Zen e no Firefox, a árvore funciona na versão homelab do editor, instalada num servidor da sua casa (veja o README).

Abra uma pasta do computador para ver e editar os arquivos dela aqui.

    Atalhos de teclado

    Comandos rápidos para escrever sem sair do teclado. As combinações usam Ctrl no Windows/Linux e Cmd no macOS. Pressione F1 no editor para buscar qualquer comando.

    Os atalhos de formatação ficam ativos quando a aba atual está em Markdown. Eles funcionam com múltiplas seleções; sem seleção, os comandos de texto inserem os marcadores e posicionam o cursor entre eles. Todos os atalhos funcionam também no modo Visual; lá, selecione um trecho para ver a barra de formatação ou digite / numa linha vazia para inserir títulos, listas, tabelas e outros blocos. Para imagens, use o botão Imagem da barra ou o item Imagem do menu /. Com um trecho selecionado, digitar aspas, parênteses, colchetes ou chaves envolve o trecho em vez de apagá-lo (em Markdown, também * _ ~).
