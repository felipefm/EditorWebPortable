Atalhos de Markdown

Comandos rápidos para escrever Markdown sem sair do teclado. As combinações usam Ctrl no Windows/Linux e Cmd no macOS.

Os atalhos de formatação abaixo ficam ativos quando a aba atual está configurada como Markdown. Eles também funcionam com múltiplas seleções; sem seleção, os comandos de texto inserem os marcadores e posicionam o cursor entre eles.

Texto e links

AtalhoAção
Ctrl/Cmd + BAplicar ou remover negrito com **texto**.
Ctrl/Cmd + IAplicar ou remover itálico com *texto*.
Ctrl/Cmd + Shift + X
ou Alt/Option + Shift + 5		Aplicar ou remover ~~tachado~~.
Ctrl/Cmd + `Aplicar ou remover código inline com `codigo`.
Ctrl/Cmd + KTransformar a seleção em link e selecionar a URL para preenchimento.

Estrutura do documento

AtalhoAção
Ctrl/Cmd + 1 a 6Aplicar ou alternar títulos de nível 1 a 6.
Ctrl/Cmd + Shift + 7Alternar lista numerada.
Ctrl/Cmd + Shift + 8Alternar lista com marcadores.
Ctrl/Cmd + Shift + 9Alternar lista de tarefas com - [ ].
Ctrl/Cmd + Shift + QAlternar citação com > .
